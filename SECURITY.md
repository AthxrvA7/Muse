# Security Policy

## Supported versions

Muse is a university project. Only the latest release on `main` receives fixes.

## Reporting a vulnerability

**Please do not open a public issue.**

Report privately through GitHub: **Security → Advisories → Report a vulnerability**
(https://github.com/AthxrvA7/Muse/security/advisories/new).

Include what you found, how to reproduce it, and the impact you expect. Do not access other users' data or disrupt the service while testing.

We aim to acknowledge reports within 3 days and to share a fix or mitigation plan within 14 days.

## Scope

In scope: the Muse backend and frontend code in this repository and the demo deployment.
Out of scope: Spotify, MongoDB Atlas, Render and GitHub themselves (report those to the vendor).

See [`docs/SECURITY_PRIVACY.md`](docs/SECURITY_PRIVACY.md) for the threat model and controls.
